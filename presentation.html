Проблема: «тихая инфляция» и скрытые списания операторов

Цифровые расходы стали незаметной черной дырой в семейном бюджете из-за трех системных манипуляций.

ПРОБЛЕМА
Манипуляция 1
Архивные тарифы и рост цен

Операторы переводят старые тарифы в архив, ежегодно индексируя абонплату на 15–30%. Пользователь годами платит за устаревший пакет услуг в 1.5–2 раза выше рыночной стоимости.

Манипуляция 2
Платные опции-«невидимки»

Раздел 4 • Математика аудита

Методология расчетов: честная стоимость владения (TCO)

Сравнение по ценнику «первого месяца» — главная ловушка маркетинга. «ТарифДетокс» считает полную стоимость за 12 месяцев.

МЕТОДОЛОГИЯ
Формула годовой стоимости владения:
TCO₁₂ = (Ppromo × Mpromo) + (Pbase × Mbase) + Csetup + Cequip + Chidden
Средняя погрешность рекламы:
+42% к рекламе
Фактор 1
Промо-периоды

Учет скачка цены: если тариф стоит 199 ₽ первые 3 месяца и 750 ₽ остальные 9 месяцев, реальная средняя цена — 612 ₽/мес, а не 199 ₽.

Фактор 2
Подключение (Setup)

Стоимость прокладки кабеля, оптического патч-корда и первичной настройки (от 0 до 2 500 ₽), распределенная на 12 месяцев эксплуатации.

Фактор 3
Аренда роутера

Аренда за 150 ₽/мес обходится в 1 800 ₽ за год. Алгоритм показывает срок окупаемости покупки собственного Wi-Fi роутера (11–14 месяцев).

Фактор 4
Скрытые опции

Платные ТВ-приставки, страхование абонентской линии и платные уведомления, которые не включены в базовый баннер провайдера.

Прозрачность: Пользователь видит точную сумму списаний за год без маркетинговых уловок

calculateTco.js 
// Честный TCO за 12 месяцев
function calculateTco(tariff, months = 12) {
  const promoM = tariff.promoMonths || 0;
  const promoP = tariff.promoPrice || tariff.price;
  const regM = Math.max(0, months - promoM);
  const oneTime = tariff.setupFee || 0;
  
  const total = (promoM * promoP) + 
                (regM * tariff.price) + 
                oneTime;
  return { total, avgPerMonth: Math.round(total / months) };
}
detectDuplicates.js 
// Поиск пересечений стриминга
function detectDuplicates(selectedSubs) {
  const groups = {};
  selectedSubs.forEach(sub => {
    (groups[sub.category] ||= []).push(sub);
  });
  
  return Object.entries(groups)
    .filter(([_, list]) => list.length > 1)
    .map(([cat, list]) => ({
      category: cat,
      waste: list.slice(1).reduce((s, x) => s + x.price, 0)
    }));
}

function downloadReminderIcs(item) {
  const icsData = [
    'BEGIN:VCALENDAR',
    'VERSION:2.0',
    'BEGIN:VEVENT',
    `SUMMARY:Отменить подписку ${item.name}`,
    `DESCRIPTION:Конец промо-периода ТарифДетокс`,
    'END:VEVENT',
    'END:VCALENDAR'
  ].join('\r\n');

  const blob = new Blob([icsData], { type: 'text/calendar' });
  saveAs(blob, `reminder.ics`);
}

Раздел 7 • Безопасность данных

Архитектура приватности: Privacy by Design и 152-ФЗ

Мы решили проблему защиты персональных данных радикально: приложение физически не способно их собрать.

152-ФЗ COMPLIANT
0B
Zero Server-Side Data

На сервере хостинга размещены только статичные файлы (HTML, CSS, JS). Отсутствует серверный бэкенд, базы данных пользователей и логи сессий. Утечка данных невозможна по определению.

✓
Чистота от трекеров и рекламы

В проекте нет Яндекс.Метрики, Google Analytics, пикселей ВКонтакте или рекламных скриптов. Браузер пользователя не передает цифровой отпечаток (fingerprint) третьим сторонам.

100%
Локальные вычисления

Все расчеты выполняются исключительно в оперативной памяти JavaScript-движка вашего устройства. При закрытии или обновлении вкладки браузера все временные параметры стираются.

Полное соответствие Федеральному закону РФ № 152-ФЗ «О персональных данных»
Сервис не является оператором персональных данных, так как не запрашивает, не хранит и не обрабатывает личную информацию.
