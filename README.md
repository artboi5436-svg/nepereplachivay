# «Не переплачивай» (Don't Overpay)

Социально-ориентированный веб-сервис честной оптимизации расходов на мобильную связь, домашний интернет, подписки и страховки в России.

## 🌟 Главные возможности
1. **Работает везде без настройки** — сайт полностью собран в единое целое. Можно открыть двойным кликом по `index.html` в любом браузере или выгрузить на **GitHub Pages**.
2. **Расчёт в браузере (Privacy First)** — без регистрации, номеров телефонов и отправки данных на сервер (152-ФЗ).
3. **Честный TCO на 12 месяцев** — расчёт полной стоимости с учётом акций, стоимости подключения и аренды оборудования.
4. **Обнаружение дублей подписок** — находим сервисы, которые уже входят в оплаченные экосистемы (Яндекс Плюс, СберПрайм) или дублируются (несколько онлайн-кинотеатров).
5. **Готовые скрипты торга и инструкции** — шаблоны для удержания скидки 30–50% («Хочу уйти»), инструкция MNP и шаблон претензии на возврат списанных средств (ст. 32 ЗоЗПП).
6. **Экспорт в календарь (.ics)** — напоминания об окончании промо-периодов и ревизии подписок.
7. **Печать в PDF и экспорт/импорт данных (JSON)**.
8. **Тёмная и светлая темы оформления** с автоматическим сохранением.

## 🚀 Запуск сайта

### Вариант 1: Локально на компьютере (без серверов)
Просто откройте файл **`index.html`** в любом браузере (Chrome, Edge, Firefox, Safari, Яндекс Браузер). Все базы данных и логика встроены в единый бандл, поэтому нет ошибок CORS или заблокированных запросов.

### Вариант 2: Публикация на GitHub Pages (Бесплатный хостинг)

Вы можете опубликовать сайт в интернет на GitHub Pages за 2 минуты:

#### Способ через сайт GitHub (в браузере):
1. Зайдите на [github.com](https://github.com) и создайте новый публичный репозиторий (например, `ne-pereplachivay`).
2. Нажмите **Add file** ➔ **Upload files** и перетащите все файлы из этой папки (включая `index.html`, папку `css`, папку `js`, папку `data`, файл `.nojekyll` и т.д.).
3. Нажмите **Commit changes**.
4. Перейдите в **Settings** репозитория ➔ вкладка **Pages** (слева в меню).
5. В блоке **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (или `master`), папка `/ (root)`
   - Нажмите **Save**.
6. Через 1–2 минуты страница обновится, и сверху появится ссылка на ваш готовый сайт вида:  
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

#### Способ через Git в терминале:
```bash
git init
git add .
git commit -m "Initial commit: сайт Не переплачивай готов к запуску"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```
После этого включите Pages в **Settings ➔ Pages ➔ Deploy from branch main / root**.

## 🛠 Сборка и обновление тарифов

Все исходные тарифы структурированы в папке `data/`:
- `data/mobile.json` — мобильная связь
- `data/internet.json` — домашний интернет
- `data/subscriptions.json` — подписки и сервисы
- `data/insurance.json` — справочные чек-листы

Если вы изменили или добавили тарифы в JSON-файлах, запустите пересборку бандла:
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```
Скрипт автоматически обновит единый автономный файл `js/app.js`.

## 📄 Структура проекта
- `index.html` — главное SPA-приложение (калькулятор, результаты, методология, прозрачность, конфиденциальность).
- `how-we-calculate.html`, `how-we-earn.html`, `privacy.html` — отдельные страницы для прямых переходов и SEO.
- `.nojekyll` — отключает обработчик Jekyll на GitHub Pages для гарантированной загрузки всех файлов.
- `css/variables.css` — цветовая палитра и переменные тем (светлая / тёмная).
- `css/style.css` — основные стили интерфейса.
- `css/print.css` — оптимизированная печатная версия отчёта.
- `js/app.js` — готовый автономный скрипт приложения со встроенными данными.
- `scripts/build.ps1` — скрипт автоматической сборки `js/app.js`.
